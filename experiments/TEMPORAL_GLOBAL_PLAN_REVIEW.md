# Temporal global matching: advisory review

Prepared 2026-10-23. This is an advisory source review, not a frozen protocol or Round 26 execution. It read only code, plans, aggregate reports and the engineering handoff. No competition observations, media, tracking/XML, targets, reserved samples, per-frame artifacts or caches were inspected; no experiments, tests, fitting or scoring ran.

## Assessment

Temporal global matching is a defensible next **alignment investigation**, but the evidence does not establish an optimal route to a better possession score. Round 25 could refine only an already selected global moment; its 454 additional mapped rows yielded just 50 safe query frames, and its next temporal-global hypothesis is explicitly untested. Earlier broadcast event heads also failed promotion: the joint-slot predictions were unchanged and replacements regressed. Better alignment, more usable clips and better possession predictions are separate hypotheses. [SUBGRID_ALIGNMENT_REPORT.md:28–43,70–79,198–205](SUBGRID_ALIGNMENT_REPORT.md#L198-L205), [BROADCAST_ACTION_REPORT.md:87–109](BROADCAST_ACTION_REPORT.md#L87-L109).

The handoff correctly puts design and dependency audit before observations. Complete that preflight, then run at most one frozen investigation if it is feasible; do not interpret this review as authorization to execute it.

## Findings and necessary decisions

1. **The dependency conflict is real at the design level.** Production coarse search reads tactical `t`; endpoint acceptance inspects neighboring coarse anchors, and interpolation uses two adjacent accepted endpoints. Giving each coarse search tactical `t±25` therefore permits endpoint decisions to reach `t±50`, and a mapped row to depend conservatively on observations within ±75. With the inherited inverse scan 125, query reach 25 and summary reach 50, the composed bound is **275**, exceeding the existing 250 contract. This is a code-derived conditional bound, not a measured Round 26 result. Failed searches, unavailable candidates, component cuts and missingness belong in it. [broadcast_alignment.py:103–110,115–156](broadcast_alignment.py#L115-L156), [alignment_coverage.py:18–54,73–83](alignment_coverage.py#L18-L54), [sports_action_features.py:71–90](sports_action_features.py#L71-L90), [ALIGNMENT_COVERAGE_PLAN.json:25–38](ALIGNMENT_COVERAGE_PLAN.json#L25-L38).

   A code-only preflight can prove a proposed bound, expose an infeasible contract, and define synthetic edge cases. It cannot establish realized coverage or correct correspondence. For example, reducing inverse radius to 100 would restore the arithmetic `100+75+25+50=250`, but would change scheduling support; it is an illustrative tradeoff, not this review's selected method. Merely lengthening the prefix or observing equality between two prefixes would not repair the fixed 250 dependency contract. Global broadcast search remains a separate all-source dependency. [alignment_coverage.py:36–59](alignment_coverage.py#L36-L59), [ALIGNMENT_COVERAGE_DESIGN_RESEARCH.md:110–126,200–210,225–231](ALIGNMENT_COVERAGE_DESIGN_RESEARCH.md#L110-L126).

2. **Freeze the new statistic and its ambiguity semantics explicitly.** The existing geometry is directed, same-team, capped at 10 metres. An RMS over temporal offsets is a different acceptance statistic from an individual-frame cost: aggregate RMS ≤2.5 does not imply each offset ≤2.5. Specify which offsets must be usable and which individual residuals, if any, must pass the original cutoff; retaining the number 2.5 alone does not preserve the old predicate. Specify candidate bounds, reflections, tie order and span definition too. [broadcast_alignment.py:65–89,103–133](broadcast_alignment.py#L65-L89), [subgrid_alignment.py:52–75,123–130](subgrid_alignment.py#L52-L75).

   A changed global winner requires its own globally evaluated runner under the declared objective. The production far mask is strictly `abs(b−winner)>250` across all four reflections; absent far runners can give valid positive-infinite margins. The Round 25 original-runner refinement is explicitly not exhaustive ambiguity checking and cannot simply certify a new temporal winner. Define whether “original winner” means the unchanged spatial winner or the new method's pre-refinement coarse winner. [broadcast_alignment.py:103–110](broadcast_alignment.py#L103-L110), [SUBGRID_ALIGNMENT_PLAN.json:9–17](SUBGRID_ALIGNMENT_PLAN.json#L9-L17).

3. **Keep the exact comparator and binding target visible.** The inherited strict inverse-25 baseline is **2,328** safe queries and **3,359** mapped public frames. The rejected Round 25 extension's 2,378 queries is not the production baseline. If the prior conjunction is retained—at least 3,000 total and at least +750 over 2,328—the effective coverage target is **3,078**, alongside retention, checkpoints and safety/replay. If preflight changes scheduling to satisfy locality, distinguish historical strict inverse-25 results from a paired strict-mapping comparator using that same new scheduler; otherwise a gain mixes alignment and scheduling changes. Freeze which comparison each gate uses before observations. [SUBGRID_ALIGNMENT_REPORT.md:70–79,132–143](SUBGRID_ALIGNMENT_REPORT.md#L70-L79), [SUBGRID_ALIGNMENT_PLAN.json:38–48](SUBGRID_ALIGNMENT_PLAN.json#L38-L48), [alignment_coverage.py:130–151](alignment_coverage.py#L130-L151).

4. **Preservation and checkpoints need independent checks.** Copying old mapping fields preserves those rows, but cannot alone prove old query support survives: inserted rows can create orientation/time discontinuities at joins. Keep separate baseline/candidate anchor graphs, evaluate queries on the final row-wise extension, and retain component cuts. Reuse checkpoint residues only if they remain absent from every new objective and acceptance gate; report eligible, mapped, usable and missing denominators. These remain correlated consistency diagnostics, not synchronization labels. [subgrid_alignment.py:139–181](subgrid_alignment.py#L139-L181), [alignment_coverage.py:39–54,73–83](alignment_coverage.py#L39-L54), [SUBGRID_ALIGNMENT_REPORT.md:109–130](SUBGRID_ALIGNMENT_REPORT.md#L109-L130).

5. **The experiment's decision value depends on a firm stop.** Geometry/neighborhood failures motivate the hypothesis, but do not prove spatial aliasing or imply recoverable matches. Preserve the exact baseline, use one predeclared method and conjunction, and close with a negative result if it fails. A positive result warrants only a later separately authorized decision about action features; it is not model promotion. Preserve failures and distinguish execution repairs from hypothesis changes. [ANCHOR_FAILURE_REPORT.md:51–80,101–113,207–211](ANCHOR_FAILURE_REPORT.md#L51-L80), [SUBGRID_ALIGNMENT_REPORT.md:142–165,198–211](SUBGRID_ALIGNMENT_REPORT.md#L142-L165).
